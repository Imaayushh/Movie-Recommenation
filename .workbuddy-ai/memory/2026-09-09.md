## Built CineMatch — C movie-recommendation program ported to React + TypeScript

Ported a user's C program (`ratings[10][5]`, `struct movie`, `matrix[3][20]`, 4-option while-menu)
into a Vite + React 18 + TS app at `D:\movie-recommendation`.

**Key decisions**
- Kept C genre ids verbatim (scify=0 … comedy=10); filled the skipped 7 with Romance, added 11 = Animation.
- C had a mismatch: `ratings[10][5]` = 10 users x 5 movies but only 5 users and 10 movies. Resolved by
  laying the same 50 numbers out as 5 users x 10 movies (C rows 0-4 -> movies 0-4, rows 5-9 -> movies 5-9).
  No value invented. Documented in README.
- Expanded catalog from 10 -> 56 movies so same-genre recommendation has real candidates.
- Core requested rule implemented in `src/lib/recommender.ts`: genre recommendations are GATED on a
  4-5 star rating. `unlocked = liked.length > 0`; when locked the genre term is forced to 0 and the user
  only gets trending + collaborative picks.
- Score = 0.6 * genre + 0.3 * collab(cosine) + 0.1 * popularity. 1-2 star ratings add a "drag" penalty at half weight.

**Gotcha hit**: declaring `Category` via `typeof CATEGORIES[number]` on an `as const` array made the
fallback object in `getCategory()` unassignable (id: number vs literal union). Fixed by declaring an
explicit `Category` interface + `CategoryId` numeric union instead.

**Verification**: `npm run verify` bundles `scripts/verify.ts` with esbuild and asserts the cold->warm
transition. Result: cold user 0 genre picks; after a 5-star sci-fi rating, 5 sci-fi picks at 88%/60%.

**Commands**: `npm run dev` (127.0.0.1:5173), `npm run typecheck`, `npm run test`, `npm run build`.

## Follow-up pass (same session)

- Expanded `scripts/verify.ts` into a real 27-assertion suite with pass/fail counters and
  non-zero exit code. No new deps: esbuild (already via Vite) bundles it to CJS, plain node runs it.
- **Bug found by the tests**: genre lift was normalised purely relatively (`lift / maxLift`), so a
  single 4-star and a single 5-star both became 1.0 — rating strength had zero effect on ranking.
  Fixed with `0.6 * (lift/maxLift) + 0.4 * (lift/(lift+2))` (RELATIVE_WEIGHT / EVIDENCE_SATURATION
  in `recommender.ts`): keeps 5-star > 4-star, keeps dominant genre winning, saturates for heavy raters.
- Added UI: genre-grouped suggestion headings ("More Sci-Fi — because you rated Inception 5-star"),
  per-card "Why this?" score breakdown, and a "Surprise me" pick that prefers genres with no lift.
- Preserved the user's original C file at `reference/original.c`.

**Tooling gotcha**: two `Edit` calls issued in parallel against the SAME file silently dropped one of
them (happened twice — types.ts and recommender.ts). Always apply edits to one file sequentially.
